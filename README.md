# نجوم لغتي

منصة تفاعلية لتعزيز الأدب والمشاركة والتعاون داخل الفصل، وإظهار أثر التقدّم للطالب وولي أمره.

إعداد وتنفيذ البرنامج: **مقرن المطيري** — مدرسة الإمام الشوكاني الابتدائية بالمذنب.

## البنية

- واجهة عامة مستضافة عبر GitHub Pages ولا تحتوي أسماء الطلاب أو أرقام هوياتهم.
- قاعدة خاصة في Google Sheets.
- واجهة خلفية خاصة في Google Apps Script تتحقق من الدخول وتنفذ العمليات.
- تُحوّل الهوية والرموز السرية إلى بصمات SHA-256 قبل إرسالها من المتصفح.

## الربط

بعد نشر `Code.gs` كتطبيق ويب، يوضع رابط النشر في `config.js` داخل `apiUrl`.
